# Delve to Life MCP server

A free, public, read-only [Model Context Protocol](https://modelcontextprotocol.io) server with practical style guidance from [delvetolife.com](https://delvetolife.com): what dress codes mean, outfit formulas for an occasion and the weather, and clothing colour combinations.

- **Endpoint:** `https://mcp.delvetolife.com/mcp`
- **Transport:** Streamable HTTP · **Auth:** none · **Data:** read-only, nothing stored
- **Official MCP Registry:** `com.delvetolife.mcp/delve-to-life`
- **Setup guide:** https://delvetolife.com/ai/

## Tools

| Tool | What it does | Example question |
| --- | --- | --- |
| `list_dress_codes` | The dress-code ladder from casual to white tie | "Which is more formal, cocktail or black tie optional?" |
| `explain_dress_code` | What one code means: a dress route, a trouser route, what to avoid | "My invitation says lounge suits. What do I wear?" |
| `suggest_outfit` | A five-piece outfit formula for occasion × weather × mood, with a palette and a link to adjust it | "What should I wear to work tomorrow? Cold and wet." |
| `colour_combinations` | Twelve tested clothing colour combinations, filterable by colour | "What colours go with olive trousers?" |
| `search_guides` | Finds the right Delve to Life guide for a question | "Is there a guide for what to wear to a funeral?" |

## Connect

**Claude** (web/desktop): Settings → Connectors → Add custom connector → `https://mcp.delvetolife.com/mcp`

**Claude Code:**
```bash
claude mcp add --transport http delve-to-life https://mcp.delvetolife.com/mcp
```

**Cursor / VS Code / other clients:**
```json
{ "mcpServers": { "delve-to-life": { "url": "https://mcp.delvetolife.com/mcp" } } }
```

**ChatGPT:** Settings → Apps & Connectors → Advanced → Developer mode → create a connector with the URL above and no authentication.

## Develop

Runs as a Cloudflare Worker with no runtime dependencies.

```bash
npm install
node scripts/smoke-test.mjs                                  # in-process tests
node scripts/smoke-test.mjs https://mcp.delvetolife.com/mcp  # live tests
npx wrangler deploy
```

- `src/index.js` — JSON-RPC / MCP handling and tools
- `src/data.js` — dress codes and colour combinations (mirrors the site's guides)
- `src/outfits.js` — the outfit-formula rules used by the site's outfit studio
- `src/guides.json` — guide index, regenerated by `scripts/build-guides.py`
